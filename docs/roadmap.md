# 发布前路线图

按优先级推进，不把以下计划写成已支持能力。

## 首次公开前

- 维护者确定 GitHub 账号、仓库可见性及开放许可证。
- 在干净 Windows x64 设备完成安装、模型校验和小样本 OCR，记录实际依赖版本与硬件。
- 用完整合成文档验证目录、多级标题、续表、合并单元格、表内图、缺页说明和最终报告。
- 推送后实际运行 GitHub Actions，修正 CI 与本机环境差异。
- 明确最小宿主能力；分别验证计划宣传支持的代理。

## 后续优化

- 提供依赖锁定及升级策略，评估 MinerU 固定版本后续兼容。
- 改善列宽、图像接缝、跨页单元格及大图布局，保留来源核验。
- 增强报告的最终计数一致性、异常输入与结构修订定位检查。
- 若需要免费 Office 后端，再实现并实测 LibreOffice 目录刷新/渲染；当前不承诺。
- 其他操作系统的完整流程需单独设计与验证，不由 Linux 纯 Python 测试推断。
