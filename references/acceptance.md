# 验收清单

这张表用于代理自查，也可让用户比较 WorkBuddy 的试做结果。结构、视觉、文字准确性分别判断。

| 检查 | 合格标准 |
|---|---|
| 输入 | 同一文件夹所有目标图片按正确顺序处理，未混入以前生成的预览 |
| 封面 | 标题、机构和版本来自原图，未沿用其他文档 |
| 章节 | 对照原目录逐条检查，正文最后的附录、风险、确认等未漏 |
| 目录 | 是 TOC 域，已由 Word 刷新，链接可跳转，抽查前中后页码正确 |
| 正文 | 可选中、复制、修改；不是整页图片或大量坐标文本框 |
| 表格 | 普通结果表可编辑，行列对应，合并单元格和跨页关系正确 |
| 所有表格的来源 | 每个表格候选都对照原图，逐个决定原生表/图/残边，不能只检查列宽 |
| 表内图片 | 逐格检查原图的监控小图是否存在，不能把有图的格交付为空白格 |
| 虚假内容 | 特别检查识别器新增的表格、年份和不相关字段是否在原图真实存在；不能按关键词盲删 |
| 数字 | 抽查至少三处数值密集区域；小文档检查全部结果表。核对小数点、单位、正负号与状态 |
| 接缝 | 每处已连接续表及切开的图/词都看过两侧源图，无漏行、重复行或断词残行 |
| 图片 | 图例、坐标和边缘完整，原有架构图、监控图未遗漏 |
| 版式 | 每页查看渲染图，无遮挡、出界、固定行高截字、无意义空白页、大片异常空白 |
| 疑点 | 看不清的文字有来源定位，未猜补，未把识别不确定说成校对无误 |
| 交付 | 文件可正常打开，结果与中间文件分离，原始图片未改变 |
| 最终记录 | 最终报告从最终文件重算计数，哈希绑定同版 Word/PDF；源图缺失写进随文件交付的说明 |

脚本 `qa_report.json` 能发现的只是空白页、域错误、表格网格和纸张外文字等机械问题；不能自动证明数值、内容、图像完整性正确，也不检查目录链接点击效果。代理必须补充目视核验。

建议首轮试做不要追求一模一样的页数。验收优先看内容完整、真实编辑能力和结构正确。发现问题先查对应来源和一小段输出，修订后重渲染相关页；没有新变化不用反复跑完整 OCR。

合格表达应区分“机械检查未发现越界”“代理已对照原图核对”和“仍有源资料限制”。replacement_characters=0 不是无缺字，图片总数不是图像完整性证明，目录页码只对实际检查过的渲染引擎及版式有效。最终 Word 或 PDF 有变化，旧记录失效。
